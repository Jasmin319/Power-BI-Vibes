In this tutorial, you'll learn how to improve donut charts in Power BI to make them clearer, more engaging, and easier to understand.

## What this project does

This project demonstrates techniques for creating more effective donut charts in Power BI.

It helps you:
- improve chart readability
- create a more polished visual design
- communicate values and proportions clearly
- make dashboards easier to scan

---

## What you'll learn

In this tutorial, you'll see:

- how to improve the appearance of standard donut charts
- how to make chart values easier to interpret
- how to design donut charts for clearer storytelling
- how to apply the approach in your own Power BI reports
