# Standardize Your Data Catalog with OKF and LLM Wiki

In this tutorial, you'll learn how to standardize an existing Power BI data catalog in Obsidian using the LLM Wiki concept and the Open Knowledge Format (OKF).

Instead of leaving your catalog as a loose collection of notes, you'll add structure, metadata, and reusable conventions that make it easier for both humans and AI agents to navigate.

---

## 🎥 Watch the tutorial

[Standardize Your Data Catalog with OKF and LLM Wiki](https://youtu.be/EMGfCK3_9Rk)

---

## 🧠 What this project does

This project upgrades a Power BI semantic model data catalog into a structured, portable knowledge base.

It allows you to:

* add YAML frontmatter for metadata consistency
* introduce index and log files for cleaner navigation
* organize notes with tags and colors
* build a semantic model overview
* create a business glossary with reliable links

---

## 🚀 What you'll learn

In this tutorial, you'll see how to:

* run a structured gap check before updating files
* apply OKF-style metadata patterns to markdown notes
* improve graph navigation with tags and color groups
* create a semantic model overview for reusable documentation
* build a business glossary that stays linkable and maintainable
* standardize documentation so it works better for teams and AI tools

## 🛠️ How to use

1. Clone or download the sample project.
2. Open the PBIP project in Power BI Desktop.
3. Open the project folder in Visual Studio Code.
4. Use GitHub Copilot to help standardize the documentation.
5. Open the Data Catalog folder as an Obsidian vault.
6. Explore the resulting structure, links, and knowledge graph.
